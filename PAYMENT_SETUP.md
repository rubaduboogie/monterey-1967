# Подключение оплаты ЮKassa

Сайт уже содержит серверные маршруты:
- `POST /api/create-payment` — создаёт платёж и отправляет покупателя в ЮKassa.
- `POST /api/yookassa-webhook` — принимает уведомление и перепроверяет платёж через API ЮKassa.

## Переменные Vercel

Обязательные для включения оплаты:
- `PAYMENTS_ENABLED=true`
- `YOOKASSA_SHOP_ID=...`
- `YOOKASSA_SECRET_KEY=...`
- `SITE_URL=https://ваш-домен`

Ключ ЮKassa хранится только в Environment Variables Vercel и никогда не попадает в браузерный код.

## Если используются чеки через ЮKassa

Включить только после выбора корректных налоговых параметров:
- `YOOKASSA_RECEIPTS_ENABLED=true`
- `YOOKASSA_VAT_CODE=...` (актуальные коды ЮKassa — до 12; в 2026 добавлены 11 для 22% и 12 для 22/122)
- `YOOKASSA_PAYMENT_MODE=full_prepayment` (либо другое допустимое значение для вашей схемы)
- `YOOKASSA_PAYMENT_SUBJECT=service` (если предмет расчёта — услуга)

Пока налоговые параметры не подтверждены, `YOOKASSA_RECEIPTS_ENABLED` лучше не включать.

## HTTP-уведомления в ЮKassa

В личном кабинете ЮKassa укажите:
`https://ваш-домен/api/yookassa-webhook`

Событие для первой версии: `payment.succeeded`.

## Что ещё нужно перед боевым включением

1. Данные продавца/исполнителя для оферты и политики обработки персональных данных.
2. Подтвердить схему чеков и НДС/без НДС.
3. Добавить Shop ID и Secret Key в Vercel.
4. Сначала провести тестовый платёж, затем включить боевой магазин.
